Bulk Clean for Slack — Privacy Policy

Last Updated: July 22, 2026
In short: Bulk Clean for Slack does not collect, transmit, sell, or share any user data. All processing happens locally in your browser. The only network calls go directly to Slack's own API on your behalf.

Overview

Bulk Clean for Slack is a browser extension that helps users bulk-delete their own Slack messages. This policy describes what data the extension accesses, how it is used, and how it is stored.

Data the extension does NOT access

  • Message content is generally not stored to disk. The one exception: "Only Delete Attachments (preserve text)" persists the edited message's text to local storage for the duration of that operation so it can be restored if the browser interrupts the job; it is deleted when the operation completes or is cancelled. All other message text stays in browser memory only.
  • No browsing history, cookies, bookmarks, or other browser data.
  • No personal information beyond your Slack user ID and workspace membership.

How data is used

  • Session token — authenticate Slack API calls (conversations.history, chat.delete, files.delete, users.list, conversations.info) on your behalf.
  • Message metadata — track which messages have been processed, enabling pause/resume/recovery.
  • User cache — display readable usernames instead of Slack IDs.

Data storage & sharing

  • No data is transmitted to external servers. All API calls go directly from your browser to Slack's official endpoints (https://slack.com/api/).
  • Session tokens are never written to disk — they live only in chrome.storage.session (memory-only, cleared on browser close).
  • No analytics, telemetry, tracking, advertising, or data brokers. Nothing is shared with any entity other than Slack's own API, at your direction.

User control

  • Pause, resume, or cancel any deletion at any time; closing the dashboard stops operations.
  • Uninstalling the extension clears all stored data.
  • Deletions require explicit confirmation, with a typed DELETE step for large batches (>100 messages).

Security

  • Session tokens are memory-only and never persisted to disk.
  • The dashboard renders inside a Shadow DOM, isolated from the host page.
  • Message sender origins are validated (*.slack.com only) before processing.
  • User text filters are guarded against regex denial-of-service (ReDoS).

Children's privacy

Bulk Clean for Slack is not directed at children under 13 and does not knowingly collect personal information from children.
